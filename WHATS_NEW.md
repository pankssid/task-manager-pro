## 🚀 **How to Use (Super Easy!)**

### No Setup Required!
All AI features work **immediately** with smart built-in responses:
1. Open http://localhost:3000
2. See AI morning routine
3. Click purple sparkle button for AI chat
4. Complete tasks to see AI insights

### Want Super-Powered AI? (Optional)
1. Get free OpenAI key: https://platform.openai.com/api-keys
2. Add to `.env.local`: `OPENAI_API_KEY=sk-your_key_here`
3. Restart server: `npm run dev`
4. Enjoy GPT-powered responses!

**Cost:** ~$0.10-0.50/month for typical usage (very cheap!)
